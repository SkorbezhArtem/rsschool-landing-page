# Coffee House

Учебный проект в рамках курса **Rolling Scopes School**.
Двустраничный адаптивный сайт кофейни «Coffee House» с переключением темы (светлая/тёмная) и интерактивным функционалом на чистом JavaScript.

## Стек технологий

- HTML5 (семантическая разметка)
- CSS3 (Flexbox, Grid, CSS-переменные, адаптив)
- Vanilla JavaScript (ES6+)

## Что сделано во 2-й части

- **Бургер-меню** для экранов <= 768px (плавное открытие/закрытие, переход по якорным ссылкам, блокировка скролла страницы).
- **Слайдер на главной:**
  - бесконечная циклическая прокрутка стрелками влево и вправо;
  - индикаторы пагинации с прогресс-баром на 5 секунд;
  - остановка автоплея и прогресса при наведении мыши и таче;
  - поддержка свайпов влево/вправо.
- **Каталог товаров (Меню):**
  - карточки динамически отрисовываются из файла `products.json`;
  - переключение категорий (Coffee, Tea, Dessert) без перезагрузки страницы;
  - кнопка «Load More» на мобильных экранах (показывает первые 4 карточки, по клику догружает остальные).
- **Модальное окно товара:**
  - открывается по клику на любую карточку;
  - интерактивный выбор размера и добавок с динамическим пересчётом цены;
  - закрытие по кнопке, клику на подложку или клавише Escape;
  - блокировка скролла страницы без дергания вёрстки.
