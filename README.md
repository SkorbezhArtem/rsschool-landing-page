## 🛠 Технологический стек

- **HTML5:** Семантическая разметка (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`). 100% валидность по стандарту W3C без ошибок.
- **CSS3:** Чистый CSS (Vanilla CSS), CSS переменные (Custom Properties), Flexbox, CSS Grid, адаптивная типографика с использованием `clamp()`, медиа-запросы `@media`, плавные переходы (`transition`).
- **JavaScript:** Синхронное переключение и сохранение темы в `localStorage` без эффекта мерцания (FOUC).
- **Normalize.css:** Сброс стилей браузера по умолчанию.
- **Ассеты:** Оптимизированное видео (WebM), векторная графика (SVG), favicon, прозрачные мокапы.

## 🚀 Локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/SkorbezhArtem/rsschool-landing-page.git
   cd rsschool-landing-page
   ```
2. Запустите любой статический веб-сервер, например:
   ```bash
   npx serve .
   ```
   или воспользуйтесь расширением **Live Server** в VS Code.
3. Откройте в браузере `http://localhost:3000` (или адрес, выданный сервером).
